# Burger Gallery Premium

Você é um especialista sênior em design de sites e copywriting focado em conversão. Construa um site institucional completo e profissional para o negócio abaixo — não um layout genérico, mas um site pensado estrategicamente para converter visitantes em clientes reais.

# SOBRE O NEGÓCIO
- Nicho: Hamburgueria Artesanal
- Nome: Burger Gallery
- Localização: R. Marina, 324 - Campestre, Santo André - SP, 09070-510, Brasil
- Contato / WhatsApp: (11) 4473-3999
- Slogan oficial: "Referência em hamburgueria artesanal"
- Horário de funcionamento: Seg a Sáb, 9h às 19h

# PÚBLICO E TOM DE VOZ
Escreva para o público que busca "hamburgueria artesanal" na região de R. Marina. Tom confiável, acolhedor e direto — nada de textos genéricos tipo "bem-vindo ao nosso site". Cada frase deve reforçar por que esse negócio específico é a escolha certa.

# ESTRUTURA OBRIGATÓRIA DO SITE
1. Hero (abertura)
2. Sobre o negócio
3. Galeria de fotos
4. Depoimentos de clientes
5. Contato / Localização
6. Rodapé

## Detalhes por seção:
- **Hero**: a headline principal (H1, maior texto da página) DEVE ser exatamente o slogan "Referência em hamburgueria artesanal" — não reescreva, não traduza, não substitua por outra frase; logo abaixo, uma subheadline curta que complementa o slogan com o principal benefício, botão de CTA levando direto para o WhatsApp (https://wa.me/551144733999). Imagem ou ilustração de alta qualidade relacionada a "Hamburgueria Artesanal".
- **Sobre**: 2-3 parágrafos curtos contando a história/diferencial do negócio, gerando confiança.
- **Galeria**: grid responsivo de fotos reais do ambiente/produtos, com hover sutil.
- **Depoimentos**: cards com nome, avatar e citação curta de clientes satisfeitos.
- **Contato**: endereço completo (R. Marina, 324 - Campestre, Santo André - SP, 09070-510, Brasil), mapa incorporado, horário de funcionamento (Seg a Sáb, 9h às 19h), botão de WhatsApp bem visível.
- **Rodapé**: repita o CTA principal, o slogan "Referência em hamburgueria artesanal", dados de contato e links rápidos.

# CONVERSÃO
- CTA principal do site: "Página de alta conversão com CTA "Fazer pedido agora""
- Botão flutuante fixo de WhatsApp em todas as seções (mobile e desktop).
- Todo bloco de conteúdo deve levar naturalmente o visitante em direção ao CTA.

# IDENTIDADE VISUAL
- Estilo: Premium
- Paleta: #D4AF37 e #0F0F10 — use com intenção (uma como destaque em CTAs, outra como base neutra).
- Tipografia: uma fonte de exibição com personalidade para títulos, uma legível para corpo — evite fontes genéricas de sistema.
- Espaçamento generoso, hierarquia visual clara.

# REQUISITOS TÉCNICOS
- Totalmente responsivo, mobile-first.
- Performance: imagens otimizadas, sem elementos que atrasem o carregamento.
- SEO básico: title e meta description específicos para "Hamburgueria Artesanal" em "R. Marina, 324 - Campestre, Santo André - SP, 09070-510, Brasil".
- Acessibilidade: contraste adequado, textos alternativos em imagens, navegação por teclado.

Construa isso como um site real, pronto para publicar — não um wireframe ou rascunho.
